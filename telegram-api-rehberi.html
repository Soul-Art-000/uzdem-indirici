Telegram API Alma Rehberi

Uzdem Ders İndirici programının istediği api_id ve api_hash değerlerini almak için izlemen gereken adımlar.

~3 dakika Ücretsiz Kredi kartı gerekmez
Başlamadan önce

Telegram hesabına kayıtlı telefon numaran hazır olsun. Giriş sırasında bu numaraya kod gönderilecek. Bilgisayardan yapman önerilir — my.telegram.org sitesi mobil tarayıcılarda sorun çıkarabiliyor.

1

my.telegram.org adresini aç

Tarayıcıyı aç ve aşağıdaki adrese git:

my.telegram.org

Sayfada API development tools bağlantısı göreceksin. Ama önce giriş yapman gerekiyor — o yüzden önce numaranı gir.

2

Telefon numaranı gir

Sayfada Your Phone Number kutusuna numaranı ülke koduyla yaz. Türkiye için başında +90 olacak, boşluk veya tire koyma.

Numara böyle görünmeli:
Your Phone Number:+905551112233

Next butonuna bas. Telegram sana bir kod gönderecek.

3

Gelen kodu gir

Telegram uygulamandan veya SMS'ten gelen mesaja bak. İçinde 5 haneli bir kod var — örneğin 38471. Bu kodu sayfadaki kutuya yaz.

Kod gelmediyse Birkaç dakika bekle. Hâlâ gelmediyse sayfayı yenileyip tekrar dene. İki adımlı doğrulaman (2FA) açıksa bu adımda ayrıca şifreni de soracaktır.

Kodu girdikten sonra Sign In butonuna bas. Artık hesabına giriş yapmış olacaksın.

4

API development tools bölümüne gir

Giriş yaptıktan sonra karşına bir menü çıkacak. Bu menüde şu başlıkları göreceksin:

  • API development tools
  • Telegram API
  • Delete account or manage apps

API development tools bağlantısına tıkla.

Not Daha önce hiç uygulama oluşturmadıysan burada boş bir form açılır. Daha önce oluşturduysan mevcut uygulamaların listesi çıkar — o zaman 6. adıma geçebilirsin.
5

Uygulama formunu doldur

Karşına üç alanlı bir form çıkar. Hepsi basit:

Alanlara şunları yaz:
App titleUzdem
Short nameuzdem
URLhttps://example.com
PlatformDesktop
Description(boş bırakabilirsin)
  • App title: Uygulamanın adı. Uzdem yazabilirsin, başka bir isim de olur.
  • Short name: Kısa isim. Sadece küçük harf ve rakam, en az 5 karakter. uzdem uygundur.
  • URL: Bir web siten yoksa https://example.com yaz, sorun olmaz.
  • Platform: Açılır listeden Desktop seç.

Sonra Create application butonuna bas.

6

api_id ve api_hash'i kopyala

Formu gönderdikten sonra bir sayfa açılır. Bu sayfada uygulamanın bilgileri listelenir. Aradığın iki değer burada:

App api_id
32610206
App api_hash
a76e982e58bcd19d922183c623a9d943

Bunlar örnek değerler — sende farklı sayılar ve harfler çıkacak. Kendi değerlerini kopyala.

  • api_id sadece rakamlardan oluşur, genellikle 7-8 hanelidir.
  • api_hash 32 karakterlik harf ve rakam karışımıdır.
Hazırsın Bu iki değeri Uzdem Ders İndirici programındaki ilgili alanlara yapıştır. Program bunları bir kez ister, sonra hatırlar.

Sık sorulanlar

Bu bilgileri vermek güvenli mi?

api_id ve api_hash, Telegram'ın resmi olarak uygulama geliştiricilere verdiği kimlik bilgileridir. Başkasıyla paylaşman gerekmez ve paylaşmaman iyi olur — ama tek başına hesabına giriş yapmaya yetmez, ayrıca telefon doğrulaması gerekir. Uzdem Ders İndirici bu değerleri sadece kendi bilgisayarında saklar.

Kod gelmiyor, ne yapmalıyım?

Birkaç dakika bekle. Kod bazen birkaç dakikada gelir. Hâlâ gelmediyse sayfayı yenileyip numaranı tekrar gir. SMS yerine Telegram uygulamasına mesaj olarak da gelebilir — oraya bak.

"Short name is already taken" hatası alıyorum

Başka birinin aynı kısa ismi kullandığı anlamına gelir. uzdem yerine uzdem2026 veya uzdemindirici gibi bir şey dene.

Daha önce API almıştım, tekrar almam gerekiyor mu?

Hayır. API development tools sayfasında mevcut uygulamaların listelenir. Uygulamanın üzerine tıklayıp api_id ve api_hash değerlerini görebilirsin.

Bu işlem ücretli mi?

Hayır, tamamen ücretsiz. Telegram API'si ücretsizdir ve kredi kartı bilgisi istemez.

Değerleri kaybettim, ne yapabilirim?

my.telegram.org sitesine tekrar giriş yap, API development tools bölümüne git. Oluşturduğun uygulama listede görünecek, üzerine tıkladığında api_id ve api_hash tekrar gösterilir.
